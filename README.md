# 远山 · 桌面机械臂

多页静态产品站，面向远山 Lite / L1 / L2 三条产品线，浅色主题。

产品与价格（格式统一为 成品 / 套件）：Lite ¥438 / ¥399（总线舵机）、L1 ¥1299 / ¥968（闭环步进电机 + 3D 打印结构件）、L2 ¥1699 / 仅成品（闭环步进电机 + CNC 钣金结构件）。L0 已取消，不再单独成线。

## 预览

直接用浏览器打开 `index.html`，或在目录内启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 在线地址

<https://levs2310.github.io/YS-Lite-arm/>

仓库 `main` 分支根目录就是站点根目录，推送到 GitHub 后 Pages 自动重新发布（通常 1 分钟内生效）。目录内的 `.nojekyll` 让 Pages 跳过 Jekyll 处理，静态文件按原样发布。

## 设计规则

- 纯白底 `#ffffff`，分区底色极浅冷蓝白 `#f2f7fd`；文字深灰黑 `#1c1c1e`，次级 `#5b6879`，分隔线 `#d9e3f0`
- 强调色参考 BrainCo 强脑科技品牌色 `#1a74bf`（Denim 蓝），渐变为同色系蓝 `#4f9fdc` → `#8ac6ea`，不使用暖色
- 光晕、渐变短线、渐变标题、状态点统一走 `--grad`；保持大面积留白的浅色调
- 标题用衬线字体，正文用无衬线字体
- 首页主视觉为三图并排（L2 / L1 / Lite），白底 1:1 实拍图等比 contain，每张图下方仅「型号名」一行 +「了解详情 →」一行，**首页不显示价格**；整卡可点击跳产品页锚点；≤760px 单列堆叠
- 价格只在产品页出现：卡片参数表用全称（`成品 ¥438 · 套件 ¥399`），对比表表头按列单独标价（¥399 / ¥438 / ¥968 / ¥1299 / ¥1699）
- 产品页直接从产品卡片开始，顶部不设小标题与索引列表；卡片不设蓝色 kicker 小字，三张卡各有 价格 / 结构 / 驱动 / 交付 参数表（L1/L2 驱动为 闭环步进电机+行星减速器，Lite 为 总线舵机）
- 「版本对比」保留 eyebrow + 一行说明，「交付与售后」只保留 eyebrow，均不设大字标题；对比表按套件款 / 成品款拆成 5 列（Lite 套件、Lite 成品、L1 套件、L1 成品、L2 成品，套件在前），表头两层，分组为 硬件与交付、软件与内容、选配加购，Lite 全勾，不设「定位」行
- 对比表单元格有细竖线分隔（最后一列不画右侧线），表格下方不再放注释文字；≤760px 横向滚动查看，不要改成卡片堆叠
- 开源页为左图右列表（`.os-layout`）：左侧 Lite 小图最大 360px，用 `mix-blend-mode: multiply` 让白底图融入浅蓝渐变背景；右侧是带编号的 `.os-entry` 条目（1 完整教程 / 2 开源链接），条目间细线分隔；≤900px 改上下单列，图缩到 300px
- 三页导航与移动端菜单的「联系」都带 `data-contact-open`，由 `script.js` 拦截默认跳转，弹出原生 `<dialog id="contactDialog">`（三页各一份）：微信 / 电话 / 邮箱三行 +「添加请备注来意」；点 ×、点遮罩、按 Esc 均可关闭，关闭后焦点回到触发元素
- 首页底部仍保留邮箱 / 手机 / 微信三行小字并靠右对齐（弹窗之外的备用入口），不用大标题与卡片
- 页脚只保留「2026.11」与「回到顶部」，不放品牌名和型号罗列
- 动效只做淡入和轻微位移
- `theme-color`（#FFFFFF）、`favicon.svg` 跟随浅色；`og-cover.jpg` 为浅色分享图
